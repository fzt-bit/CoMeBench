Design

What makes it different

Controlled difficulty

Each task varies one factor at a time, so a score drop can be attributed to a specific capability instead of being an average over confounded settings.

Automatic scoring

Every instance has a programmatic checker, so evaluation needs no human judges and runs identically on any machine.

Held-out split

A hidden test split guards against overfitting to the public leaderboard, with a submission server for blind evaluation.

Get started

Run it in four steps

terminal 
# 1. get the code
git clone https://github.com/<org>/CoMeBench
cd CoMeBench

# 2. install dependencies
pip install -e .

# 3. download the data
python scripts/download.py --root ./data

# 4. evaluate your model
python eval.py --model your-model --split test
  1. 1

    Clone & install

    Requires Python 3.10+ and a single GPU.

  2. 2

    Download data

    ~2.4 GB compressed, checksum-verified.

  3. 3

    Plug in a model

    Implement one predict() function, or use a bundled baseline.

  4. 4

    Submit

    Export predictions and upload to the leaderboard.
